# V192 Decoder DLL 说明文档

## 发布说明

### v1.2.0（当前版本）

**新增功能**
- `v192_wait_frame()`：阻塞式获取帧，支持超时设置
- `v192_get_stats()`：运行时统计（总帧数、错误帧数、当前帧率）
- `v192_load_correction()`：运行时动态重载校正文件，无需重启解码器

**变更**
- `v192_create()` 改为接受 `V192Config` 结构体，替代原来的多参数形式
- 校正文件格式升级为 JSON（原 CSV 格式不再支持）

**修复**
- 修复高帧率下偶发的帧序号跳变问题
- 修复 UDP 缓冲区溢出导致的崩溃

---

### v1.1.0

**新增功能**
- 增益/偏置校正支持（`enable_correction` 配置项）
- `v192_last_error()`：获取最近一次错误描述

**变更**
- 帧时间戳精度从毫秒提升至微秒

**修复**
- 修复通道 0 数据偶发丢失问题

---

### v1.0.0

- 初始版本，支持 192 通道 UDP 数据解码
- 基础 C API：`v192_create` / `v192_destroy` / `v192_start` / `v192_stop` / `v192_get_frame` / `v192_version`

---

## 使用说明

### 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（x64） |
| 运行时 | Visual C++ Redistributable 2019 或更高版本 |
| 网络 | 设备通过 UDP 向本机发送数据，默认端口 `4660`（0x1234） |

---

### 文件清单

```
dll/
├── Release/
│   ├── v192_decoder.dll       # Release 版本动态库（生产环境使用）
│   ├── v192_decoder.lib       # 导入库（静态链接时使用）
│   └── V192-Correction.json   # 默认校正参数文件
└── Debug/
    ├── v192_decoder.dll       # Debug 版本动态库（含调试信息）
    └── v192_decoder.lib
```

> ⚠️ 生产环境请使用 `Release` 目录下的文件。

---

### 快速集成

#### 方式一：静态链接（推荐）

1. 将 `v192_decoder.dll` 和 `v192_decoder.lib` 复制到项目目录
2. 将 `v192_decoder.h` 加入头文件包含路径
3. 在链接器输入中添加 `v192_decoder.lib`
4. 运行时确保 `v192_decoder.dll` 与可执行文件在同一目录

```cpp
#include "v192_decoder.h"
```

#### 方式二：动态加载

运行时通过 `LoadLibraryA` / `GetProcAddress` 加载，无需 `.lib` 文件，适合插件式集成。
完整示例请参考 `demo/simple_demo.cpp`。

### 数据结构

```c
/* 单通道数据 */
typedef struct {
    uint8_t  channel_id;   /* 通道编号 (0~191) */
    float    value;        /* 物理量值（已完成增益/偏置校正） */
    bool     valid;        /* 数据有效标志 */
} V192ChannelData;

/* 一帧完整数据（192 通道） */
typedef struct {
    uint32_t        frame_id;        /* 帧序号 */
    uint64_t        timestamp_us;    /* 时间戳（微秒，UTC） */
    V192ChannelData channels[192];   /* 192 个通道数据 */
    bool            frame_valid;     /* 帧有效标志 */
} V192Frame;

/* 解码器配置 */
typedef struct {
    const char* correction_file;    /* 校正文件路径（JSON），NULL 表示不使用 */
    bool        enable_correction;  /* 是否启用增益/偏置校正 */
    uint16_t    udp_port;           /* 监听的 UDP 端口号 */
    bool        verbose_log;        /* 是否输出详细日志 */
} V192Config;
```

### API 参考

#### `v192_create`

```c
void* v192_create(const V192Config* config);
```

创建解码器实例。`config` 为 `NULL` 时使用默认配置（端口 4660，不启用校正）。  
**返回**：解码器句柄；失败返回 `NULL`。

---

#### `v192_destroy`

```c
void v192_destroy(void* handle);
```

销毁解码器实例，释放所有内部资源。调用前应先调用 `v192_stop()`。

---

#### `v192_start`

```c
bool v192_start(void* handle);
```

启动解码器，开始监听 UDP 数据。  
**返回**：`true` 表示成功；失败时可通过 `v192_last_error()` 获取原因。

---

#### `v192_stop`

```c
void v192_stop(void* handle);
```

停止解码器，关闭 UDP 监听线程。

---

#### `v192_get_frame`（非阻塞）

```c
bool v192_get_frame(void* handle, V192Frame* frame);
```

立即返回最新一帧数据，不等待。  
**返回**：有新数据返回 `true`，无新数据返回 `false`。

---

#### `v192_wait_frame`（阻塞）

```c
bool v192_wait_frame(void* handle, V192Frame* frame, uint32_t timeout_ms);
```

阻塞等待下一帧数据到来。`timeout_ms` 为 `0` 表示永久等待。  
**返回**：成功获取返回 `true`；超时或出错返回 `false`。

---

#### `v192_version`

```c
const char* v192_version(void);
```

返回 DLL 版本字符串，如 `"1.2.0"`。无需句柄，可在 `v192_create()` 之前调用。

---

#### `v192_last_error`

```c
const char* v192_last_error(void* handle);
```

返回最近一次错误的描述字符串，便于调试排查。返回的字符串由 DLL 内部管理，无需手动释放。

---

#### `v192_load_correction`

```c
bool v192_load_correction(void* handle, const char* correction_file);
```

运行时加载或重载校正文件（JSON 格式）。可在解码器运行期间调用，无需重启。  
**返回**：`true` 表示成功。

---

#### `v192_get_stats`

```c
void v192_get_stats(void* handle,
                    uint64_t* total_frames,
                    uint64_t* error_frames,
                    float*    fps);
```

获取运行统计信息：

| 参数 | 说明 |
|------|------|
| `total_frames` | 累计接收总帧数 |
| `error_frames` | 累计错误帧数 |
| `fps` | 当前实时帧率 |

---

### 典型使用流程

```cpp
#include "v192_decoder.h"
#include <stdio.h>

int main() {
    /* 1. 查询版本（可选） */
    printf("DLL Version: %s\n", v192_version());

    /* 2. 配置解码器 */
    V192Config config = {0};
    config.correction_file   = "V192-Correction.json";
    config.enable_correction = true;
    config.udp_port          = 4660;
    config.verbose_log       = false;

    /* 3. 创建实例 */
    void* decoder = v192_create(&config);
    if (!decoder) {
        fprintf(stderr, "创建解码器失败\n");
        return -1;
    }

    /* 4. 启动 */
    if (!v192_start(decoder)) {
        fprintf(stderr, "启动失败: %s\n", v192_last_error(decoder));
        v192_destroy(decoder);
        return -1;
    }

    /* 5. 接收数据（阻塞方式，超时 1000ms） */
    V192Frame frame = {0};
    int running = 1;
    while (running) {
        if (v192_wait_frame(decoder, &frame, 1000) && frame.frame_valid) {
            printf("帧 #%u  时间戳: %llu us\n",
                   frame.frame_id, (unsigned long long)frame.timestamp_us);
            for (int i = 0; i < 192; i++) {
                if (frame.channels[i].valid) {
                    /* 处理 frame.channels[i].value */
                }
            }
        }

        /* 查询统计信息 */
        uint64_t total = 0, errors = 0;
        float fps = 0.0f;
        v192_get_stats(decoder, &total, &errors, &fps);
        printf("统计: 总帧=%llu  错误=%llu  帧率=%.1f fps\n",
               (unsigned long long)total, (unsigned long long)errors, fps);
    }

    /* 6. 清理 */
    v192_stop(decoder);
    v192_destroy(decoder);
    return 0;
}
```

---

### 校正文件说明

校正文件为 JSON 格式，默认路径为 `V192-Correction.json`（与 DLL 放在同一目录）。  
文件中包含每个通道的增益（gain）和偏置（offset）参数，解码器在输出 `value` 前自动应用以下公式：

```
corrected_value = raw_value × gain + offset
```

若不需要校正，可将 `enable_correction` 设为 `false`，或将 `correction_file` 设为 `NULL`。

---

### 注意事项

- 同一进程中可创建多个解码器实例，分别监听不同 UDP 端口
- `v192_version()` 不依赖句柄，可在创建实例前调用
- `v192_last_error()` 和 `v192_version()` 返回的字符串由 DLL 内部管理，**不需要也不能手动释放**
- Debug 版本会输出更多内部日志，**生产环境务必使用 Release 版本**
- 调用 `v192_destroy()` 前应先调用 `v192_stop()`，否则可能导致线程未退出
