# V192 Decoder SDK — DLL 说明

## 文件清单

```
dll/
├── Release/
│   ├── v192_filter.dll        # 主 DLL（解码器 + 点云滤波器）
│   ├── v192_filter.lib        # 导入库（链接时使用）
│   └── V192-Correction.json   # 标定文件（随 DLL 一起部署）
include/
├── v192_decoder.h             # C 公共 API（解码器）
└── v192_filter.h              # C++ API（点云滤波器）
```

> `v192_decoder` 是内部 OBJECT library，没有独立 DLL。解码器代码已静态编译进 `v192_filter.dll`。

---

## 快速集成

### CMake 项目

```cmake
target_include_directories(my_app PRIVATE path/to/V192_SDK/include)
target_link_libraries(my_app PRIVATE path/to/V192_SDK/dll/Release/v192_filter.lib)
```

将 `v192_filter.dll` 复制到可执行文件同目录。

### Visual Studio 项目

1. **C/C++ → 附加包含目录**：添加 `include\`
2. **链接器 → 附加依赖项**：添加 `dll\Release\v192_filter.lib`
3. 将 `v192_filter.dll` 复制到输出目录

## API 速查（v192_decoder.h — C 接口）

| 函数 | 说明 |
|------|------|
| `v192_create(calib_file)` | 创建解码器，加载标定文件（传 NULL 使用内置默认值） |
| `v192_destroy(h)` | 销毁实例，释放所有资源 |
| `v192_set_frame_callback(h, cb, ud)` | 注册帧回调（在 start/open 之前调用） |
| `v192_start_online(h, port)` | 启动 UDP 接收线程（默认端口 8899） |
| `v192_stop(h)` | 停止接收线程 |
| `v192_open_pcap(h, path)` | 打开 PCAP 文件 |
| `v192_read_next_frame(h)` | 解码下一帧（0=成功，1=EOF，-1=错误） |
| `v192_close_pcap(h)` | 关闭 PCAP 文件 |
| `v192_feed_packet(h, data, len)` | 手动喂入原始 UDP 负载 |
| `v192_set_distance_range(h, min, max)` | 设置距离过滤范围（米） |
| `v192_set_filter(h, cb, ud)` | 挂载自定义滤波回调（传 NULL 移除） |

### 帧回调原型

```c
typedef void (*V192FrameCallback)(const V192Frame* frame, void* user_data);
```

回调在解码线程中触发，`frame` 指针仅在回调期间有效，勿缓存指针，需保存数据请拷贝。

### 关键数据结构

```c
typedef struct {
    float   x, y, z;        // 直角坐标（米），右手系 X=正前方
    float   distance;        // 径向距离（米）
    float   azimuth;         // 水平角（度）
    float   elevation;       // 垂直角（度）
    uint8_t reflectivity;    // 反射强度 0-255
    uint8_t ring;            // 通道编号 0-191
    double  timestamp;       // 主机时间戳（秒，Unix epoch）
} V192Point;

typedef struct {
    V192Point* points;       // 点数组（库内部管理）
    uint32_t   count;        // 本帧有效点数
    uint32_t   frame_id;     // 雷达帧序号
    double     timestamp;    // 本帧时间戳
    int        is_dual;      // 非零表示含双回波数据
} V192Frame;
```

## 点云滤波器（v192_filter.h — C++ 接口）

```cpp
#include "v192_filter.h"

V192FilterParam param;           // 使用默认参数
param.close_dis_thres = 30;      // 近距离过滤阈值（cm）

V192PointCloudFilter filter(param);
filter.install(h);               // 挂载到解码器管线
// ... 接收帧 ...
filter.uninstall(h);             // 卸载
```

## 常见问题

**启动时 DLL 找不到** — `v192_filter.dll` 须与 `.exe` 在同一目录，或在 `PATH` 中。

**在线模式收不到数据** — 确认 Npcap 已安装，防火墙放行雷达 UDP 端口（默认 8899）。

**所有点坐标为 NaN** — 标定文件路径错误，或距离范围设置过窄。

**链接错误 `__imp_v192_create`** — 须链接 `v192_filter.lib`，而非 `v192_decoder.lib`（后者不存在独立导入库）。
